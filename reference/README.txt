GRAPH ENGINEERING FIELD GUIDE

Open Graph_Engineering_Field_Guide.html in a current desktop or mobile browser.
The report includes all CSS, SVG diagrams, and JavaScript; no server or internet
connection is needed to read it. External source links require internet access.

Interactive features:
- Work/evidence graph with node inspection and source-change simulation
- Hypothetical token break-even calculator
- Local, non-persistent adoption checklist and JSON export
- Copy/download buttons for all nine implementation templates
- Print layout with expanded template text

The templates/ directory contains the same reusable files separately.
All templates are drafts; execution is disabled until an authorized owner
fills project-specific facts and verifies the runtime controls. These are
contracts and examples, not a production runner or a tested security system.

The supplied anchor PDF is referenced by page but is not redistributed in this
bundle. Source metadata and primary-source links are in source-register.json.

Prepared 16 September 2026. No private repository data is included.
